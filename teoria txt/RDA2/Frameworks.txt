1. ¿Qué es un framework CSS?
Un framework CSS es un conjunto predefinido de reglas, componentes y utilidades que
simplifica el diseño de páginas web.
Ventajas principales:
•
•
•

Ahorra tiempo: ya trae botones, formularios, rejillas y tipografía.
Consistencia: mantiene un estilo uniforme en todo el proyecto.
Adaptabilidad: casi todos incluyen un sistema responsivo listo.

2. Bootstrap: rejilla y componentes listos
Bootstrap es el framework más popular del mundo, usado en millones de sitios. Se centra
en ofrecer una rejilla responsiva (grid system) y una gran cantidad de componentes
preconstruidos.
12 columnas → puedes combinar:
[ 4 | 4 | 4 ] → tres iguales
[ 6 | 6 ]
→ dos iguales
[ 3 | 9 ]
→ una pequeña y otra grande

3. Tailwind CSS: utilidades primero
A diferencia de Bootstrap, Tailwind CSS no trae componentes listos. Su enfoque es
utility-first, es decir, ofrece clases pequeñas y específicas para estilos (colores, márgenes,
tipografía, etc.), que el desarrollador combina para crear interfaces personalizadas.
Ejemplo en Tailwind
<div class="max-w-sm mx-auto bg-white rounded-xl shadow-md overflowhidden p-4">
<h1 class="text-xl font-bold text-gray-900">Título</h1>
<p class="text-gray-600">Este es un párrafo con Tailwind.</p>
</div>

Aquí no hay CSS adicional: todo se define con clases.

Tailwind:

<div class="bg-white p-4 shadow-md rounded-lg"> … </div>

6. Buenas prácticas con frameworks
1. No depender al 100%: aprende primero CSS puro.
2. Personaliza: cambia colores, tipografías y variables para que tu sitio no se vea
genérico.
3. Optimiza: en producción, elimina clases o componentes que no uses.
4. Accesibilidad: revisa contraste, foco visible y compatibilidad con lectores de
pantalla.
5. Combina lo mejor: puedes usar Tailwind para la base y Bootstrap para algunos
componentes si el proyecto lo permite.

8. Resumen
•
•
•
•

Los frameworks CSS modernos son herramientas que aceleran el diseño.
Bootstrap es ideal para empezar rápido, con componentes listos y una rejilla
responsiva.
Tailwind ofrece máxima flexibilidad con un enfoque utility-first, favoreciendo la
personalización.
La elección depende del proyecto: rapidez y estandarización con Bootstrap, o
flexibilidad y unicidad con Tailwind.
